# 出租设备 Windows 管理客户端需求文档

## 1. 项目定位

本项目不是独立的租赁业务后台，而是安装在出租设备上的 Windows 客户端，并接入现有租赁网站。

所有设备、客户、租期和远程管理操作都在现有网站中完成。Windows 客户端只负责采集设备状态、执行租期控制和接收网站下发的管理指令。

## 2. 产品目标

- 知道每台出租设备当前是否在线、是否正常运行
- 将设备与客户和租赁期限绑定
- 在租期即将结束或已经结束时提醒用户
- 支持远程延长租期、暂停和恢复设备
- 保留完整的设备状态和管理操作记录

## 3. 系统组成

本系统与现有租赁网站共用 Cloudflare D1 数据库，不为 Windows 客户端单独建立一套设备和租赁数据。

推荐的数据流：

```text
Windows 客户端 ─┐
                 ├─ 统一后端 API ─ Cloudflare D1
租赁网站 ────────┘
```

现有租赁网站是唯一的管理入口。网站通过后端 API 管理 Cloudflare D1，Windows 客户端通过客户端 API 与网站通信。客户端不直接连接 D1，避免暴露数据库凭证和绕过权限控制。

### 3.1 Windows 客户端

安装在每台出租设备上，后台运行并与服务器保持加密通信。

### 3.2 现有租赁网站管理端

作为唯一管理入口，供管理员管理设备、客户、租期、状态、通知和远程指令。

不单独开发 Windows 管理后台。

设备状态查看、设备管理和远程控制功能仅允许 `ADMIN` 管理员使用，普通客户不能访问这些管理功能。

### 3.3 统一后端 API

- 为租赁网站和 Windows 客户端提供统一接口
- 负责身份认证和权限检查
- 负责设备注册、心跳和状态更新
- 负责租期、客户和设备绑定关系
- 负责远程指令下发和执行结果回传
- 负责操作日志记录
- 负责与 Cloudflare D1 的数据读写

## 4. 数据库与网站连接

### 4.1 数据库原则

- Cloudflare D1 作为网站和客户端共用的数据源
- 设备、客户、租赁订单和租期数据只保留一份
- 网站创建或修改租赁记录后，客户端可以获取最新状态
- 客户端上报设备状态后，网站后台可以查看
- 重要数据变更需要记录更新时间和操作来源

### 4.2 建议的数据表

- `users`：管理员和后台用户
- `customers`：客户资料
- `devices`：设备基本信息和设备状态
- `device_assignments`：设备与客户的绑定关系
- `rentals`：租赁订单和租期
- `device_heartbeats`：设备心跳和在线记录
- `device_commands`：待执行的远程指令
- `device_command_results`：远程指令执行结果
- `activity_logs`：网站、客户端和管理员操作日志

具体字段需要根据现有网站数据库结构确认，优先复用已有客户和租赁表，避免重复建表。

### 4.3 API 连接要求

- Windows 客户端只连接 HTTPS API，不直接连接 D1
- 网站和客户端使用同一套设备、客户和租期业务规则
- 客户端定时请求自己的租期和远程指令
- 客户端定时提交心跳和设备状态
- API 返回明确的成功、失败和权限错误
- 支持断网重试和重复请求幂等处理
- D1 的读写操作集中在后端服务中

### 4.4 权限与设备身份

- 管理员使用网站账号登录后台
- 网站端设备状态、设备管理和远程指令功能仅允许 `ADMIN` 角色访问
- 每台 Windows 设备注册后获得独立设备凭证
- 设备只能读取和更新自己的状态
- 设备不能读取其他设备、客户或租赁订单的详细资料
- 远程指令必须由后台产生，并绑定目标设备
- 设备凭证支持撤销、重新生成和设备报废

## 5. Windows 客户端功能

### 4.1 安装与运行

- 安装客户端
- 生成或读取设备唯一编号
- 首次启动时注册设备
- 开机自动启动
- 后台静默运行
- 支持客户端自动更新
- 记录客户端版本

### 4.2 设备信息采集

- 电脑名称
- Windows 版本
- CPU 信息
- 内存容量
- 硬盘容量和使用情况
- 网络连接状态
- 电池状态（适用于笔记本）
- 最后在线时间

### 4.3 在线状态与心跳

- 定时向服务器发送心跳
- 上报设备在线状态
- 断网后自动重连
- 记录断线和恢复时间
- 断网期间在本地保存必要的租期状态

### 4.4 租期控制

- 接收租赁开始日期和到期日期
- 到期前显示提醒
- 支持配置提前提醒天数
- 到期后显示归还提示
- 支持宽限期，避免短暂断网导致误锁定
- 接收后台发出的延长租期指令
- 接收暂停和恢复指令

> 第一版建议采用明确的全屏提示或限制客户端使用的方式，不要直接破坏用户数据或强制执行不可恢复的锁定。

### 4.5 日志与异常

- 记录客户端启动和停止
- 记录网络断开和恢复
- 记录租期状态变化
- 记录远程指令执行结果
- 记录客户端异常
- 支持后台查看关键日志

## 6. 管理后台功能

### 5.1 设备管理

- 查看全部设备
- 搜索和筛选设备
- 查看设备详细信息
- 查看在线、离线和最后在线时间
- 查看客户端版本
- 设置设备状态：库存中、出租中、维修中、已报废
- 对设备进行分组
- 绑定、解绑和重新绑定设备

### 5.2 客户与租赁管理

- 添加客户
- 编辑客户信息
- 将设备分配给客户
- 设置租赁开始时间和结束时间
- 查看当前租赁关系
- 延长或结束租期
- 查看历史租赁记录

### 5.3 远程管理

- 远程延长租期
- 远程暂停设备使用
- 远程恢复设备使用
- 远程发送提醒消息
- 查看远程指令执行结果
- 重要操作二次确认

### 5.4 日志与通知

- 查看设备活动记录
- 查看管理员操作记录
- 查看异常日志
- 设备离线通知
- 租期即将到期通知
- 租期已到期通知
- 客户端异常或停止通知

## 7. 安全要求

- 管理员登录
- 管理员权限分级
- 客户端与服务器使用加密通信
- 每台设备使用独立身份凭证
- 防止伪造设备身份
- 防止普通用户随意卸载客户端
- 防止通过修改系统时间绕过租期
- 所有远程操作记录管理员、时间和结果
- 支持设备解绑和报废

## 8. 第一版 MVP 范围

第一版只实现以下功能：

1. Windows 客户端安装和开机启动
2. 设备唯一编号
3. 设备注册和绑定
4. 在线、离线和心跳状态
5. 基础设备信息上报
6. 客户与设备绑定
7. 设置和查看租期
8. 到期提醒
9. 远程延长租期
10. 远程暂停和恢复
11. 基础操作日志
12. 管理员登录和基础安全保护

## 9. 后续版本候选功能

- 远程桌面或远程协助
- 远程执行脚本
- 软件安装和卸载
- Windows 更新管理
- USB 设备管理
- 文件传输
- 屏幕截图
- 恢复出厂设置
- 位置辅助记录
- 押金和计费管理
- 手机端管理

## 10. MVP 验收标准

- 新设备安装客户端后可以注册到后台
- 后台可以看到设备在线状态和基础硬件信息
- 后台可以将设备绑定给客户并设置租期
- 客户端可以显示租期和到期提醒
- 后台延长租期后，客户端可以收到并应用新日期
- 后台暂停设备后，客户端可以显示暂停状态
- 后台恢复设备后，客户端可以恢复正常状态
- 关键操作和异常可以在后台查询
- 设备短暂断网后可以自动恢复连接
